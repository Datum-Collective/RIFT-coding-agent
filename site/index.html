The open-source AI coding agent that runs your tests

RIFT runs in your terminal. Describe a change in plain English and it reads your code, edits the files, then runs your project's own tests, typechecker and linter and shows you the real output. If a check could not run, it says so instead of calling the work done.

What RIFT does

Verifies its own work

After every change RIFT runs test, typecheck, lint, go test, cargo check or pytest, whichever your project has, and reports the results. A check that could not run is never counted as a pass.

Checks its summary against the diff

A second model compares what the agent said it did with the actual git diff and flags any claim the diff does not support.

Opens the page and looks

For UI work it drives a real browser: navigate, click, type, screenshot. It reports the console errors a screenshot never shows.

Remembers the task after compaction

The goal, plan, decisions and touched files are kept outside the model's context, so a long session does not lose the thread when it is compacted.

Works with the model you choose

Claude, GPT, Gemini, Llama, Mistral, DeepSeek and local models through one command. MCP servers work the way other clients expect.

Shares a session as a link

/share saves the session as a secret Gist on your own GitHub account and gives you a link to the diffs and check results. Recognisable secrets are removed first.

Install RIFT

macOS, Linux, WSL and Git Bash:

curl -fsSL https://raw.githubusercontent.com/Datum-Collective/RIFT-coding-agent/main/opencode/install | bash

Windows (PowerShell):

irm https://raw.githubusercontent.com/Datum-Collective/RIFT-coding-agent/main/opencode/install.ps1 | iex

Then run rift inside a project. There is nothing else to install: the download is one self-contained binary of 31 to 47 MB.

Questions

What is RIFT?

RIFT is an open-source AI coding agent that runs in your terminal. You describe a change, it edits your code, and then it runs your project's tests, typechecker and linter to check the result. It is a fork of OpenCode, released under the MIT license.

Is RIFT free?

Yes. RIFT is MIT licensed and the binaries are free on GitHub Releases. You bring your own model API key, or use one of the free models that come with it. Model usage is billed by whichever provider you pick, never by RIFT.

How is RIFT different from OpenCode?

RIFT is built on OpenCode and adds a verification layer that runs tests, typecheck and lint after every change and checks the agent's summary against the diff, a task-focused interface, browser checks for UI work, session memory that survives compaction, shareable sessions and Remotion video.

How is RIFT different from Claude Code, Cursor or Copilot?

Those are closed-source products tied to their own accounts. RIFT is open source and works with the model provider you choose. It concentrates on proving that a change works by running your own checks and showing the output.

Which AI models does RIFT support?

Anthropic Claude, OpenAI GPT, Google Gemini, Meta Llama, Mistral, DeepSeek, local models through Ollama, and many more. Set one globally, per project, or per agent.

Does my code get sent anywhere?

Only to the model provider you configure, as with any AI coding tool. RIFT has no server of its own, and shell commands, edits and network access go through a permission system you control.

RIFT is MIT licensed and is a fork of OpenCode by Anomaly, whose work makes up most of this codebase. It is not affiliated with or endorsed by the OpenCode team.
