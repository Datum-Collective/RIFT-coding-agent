Drive a real browser page and see the console errors a screenshot hides; use it to check UI work.
Actions: open (load http(s):// or file:// url; returns title, status, console errors), read (current url, title, console errors), text (visible text; optional `selector`), click and type (`selector`; type also needs `value`), screenshot (PNG; with `url` it loads first and also returns title, status, console errors), external (open `url` in the user's own browser; returns nothing). The page stays open between calls.
