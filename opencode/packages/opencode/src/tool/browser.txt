Drive a real browser page and see the console errors a screenshot hides; use it to check UI work.
Actions: open (load an http(s):// or file:// url, or a file path such as index.html; returns title, status, console errors), read (current url, title, console errors), text (visible text; optional `selector`), click and type (`selector`; type also needs `value`), screenshot (PNG; with `url` it loads first and also returns title, status, console errors), steps (run only `steps`, on `url` when given), external (open `url` in the user's own browser; returns nothing). The page stays open between calls. Use `steps` to run a whole check in one call.
